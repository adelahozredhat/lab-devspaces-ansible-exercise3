# template-ansible-collection-develop

Template collection used by **lab-devspaces-ansible-exercise3**.

Follow the lab guide in the parent directory (`../README.md` / `../README_EN.md`).
Run all `ansible-test` / `ansible-galaxy` / `ansible-playbook` commands from:

`ansible_collections/namespace_example/collection_example/`

The Dev Spaces image uses **Python 3.12** and **ansible-core 2.21**. Do not use
the old `--python 3.8` examples that used to live here.
